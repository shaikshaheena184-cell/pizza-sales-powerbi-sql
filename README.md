# 🍕 Pizza Sales Analysis — SQL & Power BI

## 📌 Project Overview

This project analyzes pizza sales data using MySQL and Microsoft Power BI.

The project combines SQL-based data analysis with an interactive two-page Power BI dashboard to understand sales performance, product performance, category trends, and customer ordering patterns.

The dataset contains 7,000 synthetic pizza sales records created for educational and portfolio purposes.

## 🛠️ Tools Used

- MySQL
- Microsoft Power BI
- DAX
- Power Query
- CSV
- GitHub

## 🔍 SQL Analysis

The SQL analysis contains 39 business questions covering:

- Data exploration
- Revenue analysis
- Order analysis
- Pizza category analysis
- Pizza size analysis
- Top and bottom products
- Monthly revenue trends
- Daily revenue trends
- Hourly order analysis
- Ranking and comparison analysis

## 📈 Power BI Dashboard

### Page 1 — Sales Overview

The dashboard analyzes:

- Total Revenue

- Revenue by Pizza Size
- Revenue by Pizza Category
- Orders by Hour

### Page 2 — Product & Sales Analysis

The dashboard analyzes:

- Category Performance
- Revenue by Category & Size

- Best-Selling Pizzas by Quantity
- Pizza Performance Details
- Interactive filters
